Overview

Dash-6.8 supports two standard CAN protocols: Rusefi and ABIT ADLM. The panel displays core engine and onboard data in a clear marine-oriented interface and is designed for everyday use in airboats and special-purpose vessels.

The system shows key operating values, status indicators and warning messages on a single display. Dash-6.8 also includes a built-in GPS module for speed indication, integrated Wi-Fi with onboard web server for connection and updates, and built-in diagnostics and warning functions.

Main parameters

  • Engine RPM.
  • Engine coolant temperature.
  • Fuel pressure.
  • Oil pressure.
  • Onboard voltage.
  • Engine hours.
  • Fuel level.
  • Vehicle speed from built-in GPS.

Status and alerts

  • Low fuel indicator.
  • Cold engine indicator.

Construction

Dash-6.8 uses a 1280×480 display with an IPS matrix, 170° viewing angle, brightness up to 450 cd/m² and operating temperature down to −30°C.

The instrument panel is built in a rigid plastic enclosure, and the housing design can be made sealed for use in harsh environments.

All elements are assembled with stainless A2 fasteners. The enclosure includes a dedicated vent valve that allows vapor release while preventing moisture from entering the housing. The panel is designed to withstand overloads up to 4 G.
