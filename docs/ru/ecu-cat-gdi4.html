Обзор

Блок управления двигателем для аэролодок: встроенная диагностика, связь по CAN и прочное исполнение для работы на воде.

Основные функции

  • Управление топливом и зажиганием по заданной конфигурации двигателя.
  • Опрос датчиков и контроль неисправностей.
  • Связь по CAN с приборной панелью и будущим модулем питания.
  • Поддержка калибровки и обновления прошивки.
  • Рассчитан на работу в составе всей электроники судна.

Применение

Для аэролодок и судов с нестандартными условиями работы: влага, вибрация и много бортовых электронных модулей.
