Воздух и топливо В работе

Наполнение цилиндров

Масса воздуха считается по давлению во впуске линейной моделью: наклон и смещение зависят от оборотов и положения впускного и выпускного распредвалов, с поправкой на температуру. Каждый банк считается отдельно, потому что у каждого свои фазы. Модель легко обращается: по нужной массе воздуха блок получает нужное давление во впуске, а через модель расхода — угол дросселя.

Топливо

Масса топлива на цилиндр = масса воздуха / (стехиометрия × целевая лямбда). Целевая лямбда — из базовой карты, поправок пуска и прогрева, обогащения для защиты деталей и коррекции по ШДК.

Гибридный впрыск

Для каждого цилиндра рассчитанное топливо делится между форсункой прямого впрыска и форсункой во впуск. Прямой впрыск — 1–3 импульса за цикл с высоковольтным профилем тока из калибровки; начало впрыска зависит от оборотов и нагрузки. Время открытия считается по модели форсунки для фактического перепада давления.

Давление в рампе

Два ТНВД, обычно по одному на банк. Целевое давление — карта 32×32 по оборотам и нагрузке; регулятор сочетает упреждение по подаче, модель рампы и интегральную часть вблизи цели.

Фазы газораспределения

Уставки четырёх валов — карты по оборотам и нагрузке. Регулирование разрешено только при достаточном давлении масла; при низком давлении валы возвращаются в базовое положение. Диагностируются обрыв и замыкание цепи клапана, недостижение цели и смещение нулевого положения.

От момента к заслонке

Момент переводится в наполнение, затем в давление во впуске, поток через заслонку и её угол: через физику, а не через таблицу «рычаг → процент».

Смесь и коррекция по ШДК

Цель λ берётся из карты с поправкой прогрева и защиты выпуска. По ШДК работают три независимых режима: PI, быстрая поправка ячейки и долгосрочная адаптация.

Топливо и импульс

Топливо цикла делится между PFI и GDI (до трёх импульсов). Время каждой части считается по модели форсунки для фактического перепада давления.
