Пуск двигателя В работе

Стратегия считает по событиям (номер впрыска, циклы двигателя), а не по секундам. Всё ниже реализовано в коде и проверено на модели, на работающем моторе ещё не проверялось.

Стратегия пуска

Счёт идёт по событиям, доза в мг. Пуск на высоком давлении с откатом на низкое, продувка рычагом в пол, затем добавка спадает по циклам.
