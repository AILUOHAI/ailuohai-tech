Логгер

Модуль «Триггер»: что это, как работает, как настроить.

Назначение

Логгер показывает каждый фронт каждого входа: что пришло в блок и что осталось после фильтров. По нему видно, откуда берутся потери синхронизации: от датчика, проводки или настроек фильтров.

Как это работает

У каждого входа две дорожки. Верхняя показывает все фронты, а отброшенные отмечены цветом и буквой причины: D - мёртвое время, S - окно после искры, L - проверка уровня. Нижняя показывает то, что получил декодер. Запись идёт потоком прямо в приложение и в блоке не хранится.

Как настроить

  1. Откройте логгерМодуль «Триггер», раздел «Логгер».
  2. Запишите сигнал«Автостарт» и прокрутка, либо «Онлайн» на работающем двигателе.
  3. Прочитайте дорожкиОтброшенных фронтов должны быть единицы, зубья идут ровно.
  4. Выберите защиту коленвалаСначала «Обычная». Сильнее ставьте только при реальных помехах: фильтр добавляет задержку.
  5. Проверьте распредвалыПереключитесь на «Распредвалы» и настройте их так же.
  6. Повторите записьСравните с прошлой: помехи ушли, зубья не пропали.

Сигнал 19

Каждый фронт каждого входа: сырой (отброшенные фильтрами блока - по причине) и после фильтров; настройки фильтров - слева, под разделами

Фильтр захвата таймераЦифровой фильтр TIM2 - коленвал (DIGITAL_1 или VR) и распредвалы на DIGITAL_2..3, один на все: импульс короче отбрасывается, фронт запаздывает на столько же. 0 - выкл, 1 - 0.13 мкс, 2 - 0.53, 3 - 1.07 (по умолчанию), 4 - 2.13, 5 - 4.27 мкс. Подбирать по коленвалу.
Мёртвое время коленвалаФронт раньше этой доли (в %) короче из двух прошлых промежутков - помеха, не принимается. Работает и до синхронизации. 0 - выкл, по умолчанию 25 %. Выше 33 % нельзя для колёс с пропуском 3 зубьев.
Гашение после искры (коленвал)Окно после искры любой катушки, мкс: в нём фронт коленвала принимается, только если промежуток не меньше 70 % ожидаемого (помехи от катушек). 0 - выкл.
Задержка датчика (коленвал)Задержка датчика и цепи входа, 0.1 мкс (50 = 5 мкс): Hall - по даташиту, VR - RC-цепь и L9966. Блок вычитает её из каждого фронта вместе с задержкой фильтра захвата - угол не уплывает с оборотами (5 мкс при 15000 об/мин = 0.45°). Проверка - стробоскоп на холостых и на высоких: метка ВМТ не должна сдвигаться.
Мёртвое время распредваловФронт распредвала раньше этой доли (в %) короче из двух прошлых промежутков этого входа - помеха. 0 - выкл, по умолчанию 25 %.
Гашение после искры (распредвалы)Окно после искры, мкс: фронт распредвала в нём принимается, только если промежуток не меньше 70 % ожидаемого. 0 - выкл.
Задержка датчика (распредвалы)Задержка датчиков распредвалов и цепи входа, 0.1 мкс; вычитается из каждой кромки вместе с задержкой фильтра захвата (DIGITAL_2, 3). Для фазы почти не важна, для фазовращателей на высоких оборотах - да.
Проверка уровня (DIGITAL_4..6)Входы на прерывании (без фильтра таймера): после фронта ножка перечитывается - уровень уже вернулся - это игла, не фронт. 1 - вкл (по умолчанию).
VR: вариант AL9966: 1 - вариант A: гистерезис по пику прошлого зуба, фильтр 1/32 периода зуба (одинаков по углу на любых оборотах), по умолчанию. 0 - вариант B: гистерезис не меньше заданного (VR: гистерезис), фильтр 2.5 мкс.
VR: фильтрФильтр выхода компаратора L9966 (вариант A - 1/32 периода зуба, B - 2.5 мкс). 1 - вкл (по умолчанию).
VR: автогистерезисГистерезис по пику сигнала прошлого зуба (большой сигнал - больший порог). 0 - ручной (VR: гистерезис). 1 - вкл (по умолчанию).
VR: гистерезисРучной гистерезис (или минимум в варианте B): 1 - 120 мВ, 2 - 230, 3 - 400, 4 - 1050, 5 - 1600 мВ, 7 - без гистерезиса (внешние 10+10 кОм).
VR: фильтр спадаСпад VRS_OUT (по нему ловится зуб): 0 - маска - сразу на переходе через ноль, дребезг после не виден время фильтра (по умолчанию, точнее); 1 - фильтр - ждать, пока сигнал устойчиво низкий.
VR: гистерезис после фильтраГистерезис переключается по выходу после фильтра (1) или прямо по компаратору (0, по умолчанию).
VR: двойной фронтНовый гистерезис - со второго фронта, а не с первого (вариант B): помогает первому зубу после пропуска. 1 - вкл (по умолчанию).
VR: минимальный гистерезисПринудительно минимальный гистерезис (HI1 / HI3 по варианту) - для очень слабого сигнала. 0 - выкл.
VR: гистерезис при пускеПока вал стоит и первые зубья (даташит: первые переключения - на малом ручном): 1 - 120 мВ (по умолчанию) ... 5 - 1600 мВ, 7 - без.
VR: зубьев до рабочей настройкиПосле остановки - столько зубьев на пусковой настройке, потом рабочая. По умолчанию 30.
VR: проверка датчикаПока вал стоит - раз в 5 с проверка датчика VR: обрыв, КЗ на землю, КЗ на АКБ (код неисправности). 1 - вкл (по умолчанию).
