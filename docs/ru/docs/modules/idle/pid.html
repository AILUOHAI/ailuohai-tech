Регулятор

Модуль «Холостой ход»: что это, как работает, как настроить.

Ctrl K
НазначениеКак это работаетКак настроитьЕсли что-то не такЧто есть в приложении

Назначение

Два регулятора держат обороты. Основной работает через воздух, быстрый через зажигание.

Как это работает

Основной PID сравнивает обороты с целью и меняет запрос момента, а заслонка его исполняет. Воздух доходит до цилиндра с задержкой, поэтому для быстрых провалов есть второй путь. Блок держит чуть больше воздуха, чем нужно, на величину запаса момента, а зажигание ставит немного позже лучшего угла. Когда обороты падают, зажигание сразу идёт раньше и отдаёт запас. Затем основной регулятор доводит воздух, и зажигание возвращается в середину запаса. Запас не превышает 60 % момента холостого хода. Пока этап 3 выключен, зажигание идёт по карте и работает один воздух.

Как настроить

  1. Откройте разделМодуль «Холостой ход», раздел «Регулятор».
  2. Настройте PIDНа вкладке «PID» числа идут по порядку: kp, ki, kd, фильтр D, минимум и максимум выхода, минимум и максимум накопленной части, мёртвая зона. Заводские: kp 0,15, ki 0,6, kd 0,002.
  3. Меняйте по одномуСначала kp, затем ki. Рост kd только при необходимости.
  4. Включите этап 3На экране «ХХ сейчас», когда этап 2 держит обороты ровно.
  5. Задайте запасКривая по ОЖ, по умолчанию от 25 до 12 Н·м.
  6. Настройте быстрый регуляторПо ошибке 0,5 Н·м на об/мин, по скорости падения 0,02.
  7. СохранитеНажмите «Сохранить в ЭБУ».
