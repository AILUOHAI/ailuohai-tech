Барометр

Модуль «Датчики»: что это, как работает, как настроить.

Ctrl K
НазначениеКак это работаетКак настроитьЕсли что-то не такЧто есть в приложении

Назначение

Барометр измеряет атмосферное давление. Он нужен для расчёта воздуха и работы на разной высоте.

Как это работает

Датчик стоит на плате блока. Блок проверяет его тремя способами: по допустимому диапазону, по скорости изменения и по сравнению с MAP на стоящем двигателе. Настоящая погода не меняет давление быстрее, чем на 2 кПа за 10 с. Если барометр неисправен, блок берёт MAP на стоящем двигателе, затем последнее хорошее значение, затем 101,3 кПа.

Как настроить

  1. Откройте разделМодуль «Датчики», раздел «Барометр».
  2. Сверьте показаниеПри неработающем двигателе значение должно совпасть с MAP и с прогнозом погоды для вашей высоты.
  3. Проверьте состояниеВ поле «Для двигателя» должно быть «исправен».
  4. Посмотрите ошибкиНа вкладке «Ошибки и ограничения» не должно быть активных кодов P2226…P2229.
