Топливо пуска

Модуль «Пуск»: что это, как работает, как настроить.

Ctrl K
НазначениеКак это работаетКак настроитьЕсли что-то не такЧто есть в приложении

Назначение

Раздел задаёт, сколько топлива получает цилиндр на прокрутке. Доза задаётся в миллиграммах на цилиндр.

Как это работает

Основа — кривая «Доза» по температуре пуска: чем холоднее, тем больше, потому что на холодных стенках испаряется меньше топлива. Дальше идут множители. Спад по впрыскам: первые два впрыска цилиндра полные, к восьмому доза снижается, чтобы не залить свечи. По давлению: при низком давлении распыл хуже, поэтому топлива больше. По оборотам: по умолчанию без поправки. Добавляются множители повторного и горячего пуска и адаптации. Время импульса считается по фактическому давлению в рампе.

Как настроить

  1. Откройте разделМодуль «Пуск», раздел «Топливо пуска».
  2. Настройте дозуНа вкладке «Доза» по умолчанию от 120 мг при −30 °C до 36 мг при 110 °C. Сначала добейтесь пуска при текущей температуре.
  3. Настройте спадНа вкладке «Спад по впрыскам»: если первые вспышки есть, а потом двигатель заливает, снижайте поздние впрыски.
  4. Проверьте поправкиВкладки «По давлению» и «По оборотам».
  5. Проверьте начало впрыска60° до ВМТ на высоком давлении.
  6. СохранитеНажмите «Сохранить в ЭБУ».

Топливо 5
Доза пускаТопливо на цилиндр на прокрутке по температуре пуска, мг. Основа: остальное - множители (спад по впрыскам, давление, обороты, повторный и горячий пуск, адаптация).
Спад дозы по впрыскамМножитель дозы по номеру впрыска цилиндра и температуре пуска. Первые впрыски - полная доза (плёнка на стенках), дальше меньше, чтобы не залить свечи.
Доза по давлению рампыМножитель дозы по давлению в рампе на прокрутке. Низкое давление - распыл хуже, топлива больше.
Доза по оборотам прокруткиМножитель дозы по оборотам прокрутки (1 - без поправки).
Начало впрыска на пускеПуск на высоком давлении: впрыск в такт сжатия, ° до ВМТ.
