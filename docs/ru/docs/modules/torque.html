Моментная структура

Рычаг и регулятор ХХ просят момент, ограничения забирают его минимумом, а исполняют два пути: воздух медленно и угол зажигания быстро. Поэтому ограничения плавные, без отсечек.

Обозначения:Как читать схемуЗначкиСокращения

Резерв момента

Воздуха держат больше, чем нужно, а лишний момент съедает поздний угол. Когда момент нужен сразу, угол возвращается к оптимальному за один цикл, не дожидаясь наполнения коллектора.

Обозначения:Как читать схемуЗначкиСокращения

Защиты ступенями

Каждая причина даёт только долю момента от 0 до 1, действует самая строгая. Нижняя ступень это режим «домой», а не ноль.

Обозначения:Как читать схемуЗначкиСокращения

Регулятор оборотов

Опытный режим, по умолчанию выключен: рычаг задаёт обороты, а момент блок подбирает сам с упреждением по винту.

Обозначения:Как читать схемуЗначкиСокращения
