Protections and fault reactions In progress

The main requirement: the boat must get back to shore. Every fault has a code in OBD format and a reaction level. If several are active, the strictest applies. Torque is reduced smoothly, without cutting fuel or spark.

LevelReactionExamples
R0Fault code onlyKnock sensor noise, wideband sensor
R1Torque and filling limitMAP sensor replaced by model
R2Limp mode: as R1 plus an rpm limit (~2500) to get homeThrottle not responding, both lever channels or rail sensor failed
R3Engine stopNot assigned to any fault by default

Coolant, oil, exhaust and gearbox temperatures and oil pressure reduce torque in four steps. The lowest step is a “get home” mode, not zero.

Injection and spark are timed by hardware timers. A silent second core is detected as a fault. An external power-management chip with a watchdog supervises the processor.

Stepped protections

Each cause gives only a torque fraction from 0 to 1, and the strictest applies. The lowest step is a get-home mode, not zero.
