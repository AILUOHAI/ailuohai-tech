How to read diagrams

Blocks, icons and symbols in the structure diagrams

Ctrl K
Diagram elementsIcons

Diagram elements

A blue oval is an input, a teal block is a curve or map, white blocks are arithmetic, purple is logic, orange is dynamics and a green oval is an output.

Icons

A thermometer is temperature, a gauge is pressure, a gear is rpm, a plug is spark, an injector is fuel, a shield is protection.
