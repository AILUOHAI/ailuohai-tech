How to read diagrams

Blocks, icons and symbols in the structure diagrams

Reading orderBlock typesDiagram elements

Reading order

  1. Read from left to rightThe signal travels along the arrows from inputs on the left to outputs on the right.
  2. Look at the colourA block's colour tells its type: input, table, arithmetic, logic, dynamics or output.
  3. Find the key blockThe decision is often made by a Minimum block: the strictest limit passes.
  4. Open the submodelA Submodel block has its own diagram, described on that function's page.
  5. An unfamiliar abbreviationLook it up under Abbreviations, and an icon under Icons.

Block types

Inputs and outputs

Input signalBlue oval: a sensor or engine state
OutputGreen oval: the function result
CalibrationGrey dashed block: a setting you can change
ConstantGrey block: a fixed number

Tables

2D curveY = f(X), 16 points
3D mapZ = f(X, Y), 32×32, corrections 16×16

Arithmetic

SumY = A ± B ± C, the sign is at the arrow
MultiplyY = A × B
DivideY = A ÷ B
Square rootY = √A
MinimumY = min(A, B): the smaller passes
MaximumY = max(A, B): the larger passes
Range limiterY = X within Min…Max

Logic

SwitchC = 0: Y = A; C = 1: Y = B
CompareY = A > B
ANDY = 1 if all inputs are 1
ORY = 1 if at least one input is 1
NOTY = not X
Rising edgeY = 1 at the 0 → 1 transition
HysteresisOn above Hi, off below Lo

Dynamics

DebounceY = X if the value holds longer than T
On delayThe rising edge arrives T later
Off delayThe falling edge arrives T later
First-order filterSmoothly follows the input with time constant T
Rate limiterLimits the rise and fall rate
IntegratorAccumulates the input over time, within limits
DerivativeRate of change of the input, filtered
PID controllerY = feed-forward + Kp·e + I + D, e = target − actual

Submodel

SubmodelA function with its own diagram

Diagram elements

A blue oval is an input, a teal block is a curve or map, white blocks are arithmetic, purple is logic, orange is dynamics and a green oval is an output.
