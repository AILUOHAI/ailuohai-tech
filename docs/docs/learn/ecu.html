The control loop

The ECU works in a closed loop: it measures the engine state, calculates cylinder filling, fuel mass and spark timing, and commands the actuators. The result is measured again, so the unit compensates for temperature, pressure, wear and part-to-part variation.

Sensorscrank and cam angle, MAP, temperatures, rail pressure, lever, lambda, knock
↓
Model in the ECUtorque, air, fuel mass, injection timing, spark timing
↓
Actuatorsinjectors, coils, throttle, high-pressure pump, wastegate, cam phasers
↓
Engineits response returns through the sensors

Time scale

In a four-stroke engine each cylinder fires once every two revolutions. That sets the time the unit has to prepare the next injection and spark.

What Cat-GDI8 is

An ECU for gasoline engines of up to 8 cylinders with direct injection (GDI), port injection (PFI) or a hybrid layout, with torque-based control, electronic throttle, boost and cam phasers.
