Electronic throttle and torque request

There is no mechanical link between the lever and the throttle. Lever position sets a torque request; the coordinator takes idle control and limits into account, then the model calculates the required filling and throttle position. This is why the rev limiter and protections act regardless of lever position.

Load source: MAP or throttle

Speed-density. Filling is calculated from intake pressure, rpm, temperature and cam positions. The main mode; it also works with boost.
Alpha-N. Load is taken from throttle angle and rpm. Used when MAP fails and on engines with unstable vacuum, for example with individual throttle bodies.
