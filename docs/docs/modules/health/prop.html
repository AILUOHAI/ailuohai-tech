Propeller

“Engine health” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The section sets how the ECU learns the propeller load. The propeller works like a brake dyno: in a steady mode its torque grows as the square of the engine speed, and the ECU remembers this factor.

How it works

In a steady mode the ECU divides the model shaft torque by the square of the engine speed and slowly learns the factor k. The mode counts as steady when the speed is at least 1500 rpm, the torque at least 20 Nm, the speed changes slower than 150 rpm per second, and this holds for 2 s. The learning time constant is 120 s; during the first quarter of this time k is learned 10 times faster, so that the sign works already on the first run. The Propeller load sign compares the reading over the last 5 s with the learned k and starts after a quarter of the learning time. The learned k is saved in the ECU memory when it changes by more than 2 %, and is also used by the lever-sets-speed mode. The steady-mode threshold on the speed change rate also applies to the other health signs. After a propeller change, k is learned again for the new propeller.

Setup

  1. Open the sectionEngine health module, Propeller section.
  2. Set the thresholdsSpeed and torque from which the propeller loads the engine noticeably.
  3. Set the steady modeSpeed change rate and the time the mode holds.
  4. Set the learning timeLonger - k learns slower and is less affected by waves and wind.
  5. SavePress Save to ECU.
