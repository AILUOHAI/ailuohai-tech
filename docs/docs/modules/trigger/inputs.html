Inputs

“Trigger” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This is where you state which ECU inputs the crankshaft and camshaft sensors use and how the signal behaves while a tooth passes the sensor. Everything the unit computes by angle depends on it: injection, spark, cycle phase and cam phasers.

How it works

The crankshaft connects either to the inductive VR input or as a Hall sensor on DIGITAL_1. There can be up to four camshafts: intake A and B, exhaust A and B, each on its own DIGITAL_1…6 input. One input cannot serve two sensors, and a busy input is unavailable in the list. When several healthy camshafts are present, they all vote for the cycle phase, and a tie is decided by the main one: intake A, intake B, exhaust A, exhaust B.

Setup

  1. Open the inputsTrigger module, Inputs section, Sensors tab.
  2. Choose the crank inputVR for a two-wire inductive sensor, Hall for a three-wire sensor.
  3. Set the signal on a toothFor Hall, choose the level the sensor outputs on a tooth. VR teeth are always detected at the zero crossing.
  4. Assign the camshaftsEach shaft gets its own input. Leave unused ones as “not used”.
  5. Write to the ECUThe engine must be stopped. Press “Write to ECU”.
  6. Check the errorsErrors tab: sensor codes and ECU counters after cranking.
