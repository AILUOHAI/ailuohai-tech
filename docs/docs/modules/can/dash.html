Dash

“CAN” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The section sets up work with the Dash 6.8 panel: pairing, the start/stop button, driver modes and the actuator test from the dash.

How it works

The ECU sends engine data to the dash (fast data 50 times a second, temperatures, pressures and state 10 times a second) and up to 5 active faults, the most dangerous first; the dash shows them in turn. The dash sends an alive message 10 times a second with the start/stop button, GPS speed and fuel level, and commands: fuel, power, quiet mode, codes, actuator test. Every command carries a check sum with the key of this ECU, so a foreign or unpaired dash cannot control the engine. To pair: turn on Allow pairing, choose Pair on the dash, then turn it off. Unpair changes the key - every dash has to be paired again. The starter is not allowed by default. Start by the button: press and hold - hold 1 s, then the ECU cranks by itself until the engine runs, but not longer than 10 s; crank while held - the starter turns only while the button is pressed. Start is allowed only with the lever at most 5 % and the starter allowed; the starter is released at 600 rpm, starter protection is 10 s with a 5 s pause. Stop - hold the button 2 s on a running engine: injection and spark are switched off until the shaft stops. If the link with the dash is lost, the button counts as released. Driver modes: torque factors cruise, normal, full (0.5, 0.8, 1.0), quiet mode limits the engine speed (3000 rpm), all smoothly through the common torque limiter. Fuel 92 switches to the 92 map at once, 100 raises the octane factor smoothly, auto learns by knock. Actuator test (engine stopped only): 10 pulses per injector and coil, pump 3 s. CAN has not been checked on the board yet: work with the dash, a scanner and a marine display has only been checked on the simulator.

Setup

  1. Open the sectionCAN module, Dash section.
  2. Pair the dashTurn on Allow pairing, choose Pair on the dash, then turn the permission off.
  3. Allow the starterTurn on Starter allowed and choose how to start from the dash.
  4. Set the modesPower factors and the quiet mode engine speed.
  5. SavePress Save to ECU.
