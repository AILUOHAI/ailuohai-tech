ECU equipment

“Engine” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The section shows how many channels the ECU has: GDI and PFI injectors, coils, high-pressure pump valves, camshaft inputs, low-side outputs, H-bridges, CAN lambda modules, CAN buses and LIN.

How it works

The engine configuration cannot exceed these numbers: options beyond the equipment are grey in the Configuration section, with the reason. For example, no more cylinders than injector and coil channels; no more cam phasers than camshaft inputs; hybrid injection only if there are PFI channels for all cylinders. For now the equipment is taken from the board documentation; the ECU will report it itself later. The picture shows the simulator equipment.

Setup

  1. Open the sectionEngine module, ECU equipment section.
  2. Compare with the engineAt least as many injector and coil channels as cylinders; at least as many camshaft inputs as cam phasers.
  3. Go back to the configurationGrey options in Configuration are those without enough channels.
