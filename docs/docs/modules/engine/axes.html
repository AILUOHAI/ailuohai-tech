Table axes

“Engine” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The section sets the ranges of the common table axes: engine speed, filling, coolant temperature, battery voltage, rail pressure and intake pressure. This is the second step after the engine configuration: many tables are tied to these axes, so until the axes are set there is no point in tuning the tables and other parameters.

How it works

An axis is common to all tables that use it. Changing its range recalculates all of them: the axis points are stretched and the table values are moved by interpolation. That is why axes can be changed only with the engine stopped, with the Apply button. Each axis has its allowed range: engine speed 0…15000 rpm, filling 0…400 %, coolant −60…150 °C, battery 4…36 V. Pressure axes (rail, intake) follow the calibration of their sensor: change the sensor and all tables with this axis are recalculated; the Sensor → button leads to its calibration. Axes of a single table and fixed axes are under Other axes; they are easier to edit in the table itself. The picture shows simulator values.

Setup

  1. Stop the engineAxes change only with the engine stopped.
  2. Open the sectionEngine module, Table axes section.
  3. Set the rangeLowest and highest axis value, for example engine speed up to the engine maximum. Do this before filling any table.
  4. ApplyPress Apply: all tables with this axis are recalculated.
  5. SavePress Save to ECU.
