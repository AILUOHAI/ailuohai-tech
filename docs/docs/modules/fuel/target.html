Lambda target

“Fuel & mixture” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets the mixture the unit holds in every mode: the lambda target by speed and filling.

How it works

The unit calculates the air mass in the cylinder and divides it by the stoichiometric 14.7 and by the lambda target. The result is the fuel mass per cycle in milligrams. The map sets lambda by speed and filling. On a cold engine it is multiplied by the warm-up enrichment curve from the Start module. If the exhaust temperature model is above the limit, lambda comes from the protection map when that is richer. The target changes smoothly, so fuel and torque do not jump. The factory map: lambda 1.0 up to 80 % filling, then richer down to 0.88 at 110 %. Each bank has its own target, because exhaust protection is calculated separately.

Setup

  1. Open the mapFuel & mixture module, Lambda target section.
  2. Part loadKeep lambda 1.0: the wideband works best there and consumption is lower.
  3. Full loadEnrich smoothly, usually to 0.85-0.90. Do not lean out power modes.
  4. Check with the widebandIn steady modes the measured value must match the target. If not, check the Air module first.
  5. SavePress Save to ECU.
