Exhaust protection

“Fuel & mixture” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section protects the exhaust manifold, turbo and catalyst from overheating by enriching the mixture.

How it works

The unit does not use an exhaust gas temperature sensor, and the temperature comes from a model. The map sets the steady temperature by speed and filling. Factory: from 350 °C, rising with filling and speed. A curve adds heating from late ignition, factory up to +70 °C at 35°. Today only knock retard goes into it. Late ignition used to reduce torque is not counted yet. The model follows the steady value with a lag, factory 1.5 s. Above the limit, factory 900 °C, protection turns on, and it turns off a hysteresis lower, factory 30 °C. While protection is active, lambda moves smoothly to the Protection lambda map (factory 0.82) if that is richer, and wideband correction is off. The model runs for each bank.

Setup

  1. Find the limitsGet the allowed manifold and turbo temperature from the manufacturer.
  2. Check the modelIf you have an exhaust temperature sensor, compare it with the model in several modes and correct the map.
  3. Set the protection lambdaUsually 0.80-0.85. Richer means a cooler exhaust but higher consumption.
  4. SavePress Save to ECU.
