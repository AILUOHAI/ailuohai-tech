Lambda control

“Fuel & mixture” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets how the unit corrects fuel from the wideband oxygen sensors so the mixture matches the target.

How it works

Three modes run, and each can be turned off. The PI regulator compares measured lambda with the target and gives a correction of up to ±20 %. Factory gains: P 0.2, I 1.0. The fast trim starts if the engine has stayed in one cell of the 16×16 grid for more than 30 cycles: that cell's factor takes over the PI correction at a rate of 2 per second, but no further than ±20 %. Its values are kept until power-off. Long-term adaptation very slowly, at 0.05 per second, moves the total correction into its own map for each bank, within 0.75-1.25. The map is stored in the unit. Correction works when the wideband is ready, coolant is at least 40 °C, exhaust protection is off, intake pressure changes slower than 50 kPa/s and 1 s has passed since the last mode change. At other times the last PI correction is kept. If the wideband is lost, the PI correction is reset to zero.

Setup

  1. Check the widebandIn the Sensors module the sensor must be ready and lambda on a warm engine must be plausible.
  2. PI firstTurn off the fast trim and adaptation and make sure the PI correction is small and does not hunt.
  3. Turn on the fast trimIt quickly removes the error in modes where the engine runs for a long time.
  4. Turn on adaptation lastOtherwise it learns the base tuning mistakes.
  5. Reset adaptationOn the bank tab select all, type 1 and press Apply, then Save to ECU.
