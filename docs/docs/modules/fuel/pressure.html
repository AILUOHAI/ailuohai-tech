Fuel pressure

“Fuel & mixture” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets the GDI rail fuel pressure held by the high-pressure pump.

How it works

The map sets the target pressure by speed and filling. Factory: 5 MPa at idle, up to 20 MPa at full load. The target changes no faster than the set rate, factory 40 MPa/s. After the start the target rises from the current pressure. For each pump stroke the unit orders a volume: injector use per stroke, leakage, a share of the pressure error and an integral part near the target. The volume is converted into the pump valve closing moment using the cam profile. Above 25 MPa delivery stops and resumes after a 2 MPa drop. If the pressure sensor is faulty, the pump is not regulated. The pump itself and its regulator are set up in the Actuators module, HP pump section.

Setup

  1. Set up the pumpIn the Actuators module, enter the HP pump data and check the rail pressure sensor.
  2. Set the targetLower at idle, higher under load. Do not exceed the injector and pump limits.
  3. Check trackingDuring acceleration the pressure must follow the target without dips or overshoot.
  4. SavePress Save to ECU.
