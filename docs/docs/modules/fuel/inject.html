Injection

“Fuel & mixture” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets when and in which parts fuel enters the cylinder: GDI start of injection, splitting into pulses and the PFI injector share.

How it works

The Cycle scheme tab switches the mode and shows the cycle of cylinder 1 right now. Start of injection is set in degrees before compression TDC. The factory 300° injects on the intake stroke for a homogeneous mixture. With two or three pulses, the second and third take their share of GDI fuel from maps, multiplied by a coolant factor. Together they take no more than 90 %, and the first pulse gets the rest. A part goes back into the first pulse if it is shorter than the injector minimum pulse, if it cannot follow the previous one with a pause for the injector supply to recharge, or if it does not start after the previous one ends. Above the set speed (factory 4500 rpm) and during cranking there is one pulse. With PFI, part of the fuel from the PFI share map goes to the port and the rest to GDI. During cranking only GDI works. After the start the PFI share rises from zero: longer when cold, from 8 s at −20 °C to 1.5 s at 90 °C. If a PFI pulse would be shorter than the minimum, all fuel goes to GDI.

Setup

  1. Start simpleOne GDI pulse, PFI off. The engine must run smoothly in all modes.
  2. Start of injectionKeep injection on the intake stroke. Late injection on compression is only for special modes.
  3. Two pulsesTurn on after the fuel is tuned. Check on the cycle scheme that the second pulse is really there.
  4. PFITurn on if PFI injectors are fitted and set up in the Actuators module. Start with a small share.
  5. SavePress Save to ECU.
