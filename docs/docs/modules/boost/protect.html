“Boost” module: what it is, how it works, how to set it up.

Purpose

Overboost protection is still in development and this section has no settings. This page describes which checks already work and which do not exist yet.

How it works

Electric wastegate monitoring already works: on a sensor fault, tracking error, stiff travel or bridge error, the bridge is switched off, a code is stored and the filling limit drops to 60 %. Without current the valve returns on its spring and may close. The factory filling limit is far above atmospheric, so in that case it will not hold the pressure back. If the intake pressure sensor fails, the unit moves to a calculation from throttle, speed and barometer and remembers that boost may be allowed only after a new start. Nothing uses this flag yet because there is no regulator. Planned: overboost detection with the wastegate fully open and a torque limit, a code for low boost, and boost shut-off on a boost sensor fault.

Setup

  1. Check the wastegateIn the Actuators module, make sure there are no active errors.
  2. Check the pressure sensorWith the engine stopped, the reading must match the barometer.
  3. Watch the pressureIf a turbo engine is run anyway, keep it unloaded and monitor boost pressure.
  4. Stop if pressure risesPressure rising without load means the wastegate is not open.
