Ignition coils

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

A coil stores energy and releases it to the spark plug as a spark. This section sets how long and with what current it charges.

How it works

The charging time is called dwell. Passive coils are charged by the MC33810 chip: it limits the current to the nominal value, shuts the coils off at the fault current and cuts an excessively long dwell by itself. The unit sees when the current reaches nominal and, with learning on, adjusts dwell so that nominal arrives just before the spark. Coils with a built-in igniter use the dwell from their datasheet.

Setup

  1. Open the sectionActuators module, Ignition coils section.
  2. Set the dwellOn the Dwell and battery dwell tabs, enter the values from the coil datasheet.
  3. Set the currentsOn Current and spark, set the nominal and fault current.
  4. Remove fuel and check wiringLay the plugs in their coils on ground. On Outputs, check the spark on each cylinder.
  5. Check the errorsOn Errors & limits there must be no active codes.
  6. SavePress Save to ECU.
