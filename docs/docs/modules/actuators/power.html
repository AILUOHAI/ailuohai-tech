Power control

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Power switches feed the banks, injector drivers, coils, pumps and starter, watch their current and shut them off on a fault.

How it works

The board has eight BTS7002 smart switches. Every 10 ms the unit reads the current of each one. A current below the lower limit while on means an open circuit, and an average above the upper limit means an overload: the switch turns off and retries. The switches of one bank share a control pin, so when one trips, the other turns off too. A bank can be switched off by hand only with the engine stopped, and this lasts until the unit restarts.

Setup

  1. Open the sectionActuators module, Power control section.
  2. Look at the switchesThe Switches tab shows each switch's current, state and highest value.
  3. Set the limitsOn the limit tabs, set the working current range. Zero as the lower limit turns off the open-circuit check.
  4. After fixing the causePress Clear fault.
  5. SavePress Save to ECU.
