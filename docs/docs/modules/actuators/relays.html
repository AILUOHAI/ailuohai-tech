Pumps & relays

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Two lift pumps feed fuel to the HPFP. This section sets the delivery scheme, operating mode and reaction to failures.

How it works

There are three schemes. In the first, a mechanical regulator holds pressure and PWM follows an rpm curve. In the second there is no regulator and PWM holds pressure from a sensor. In the third there is both a regulator and a sensor: the target is just below the regulator setting, so the pump delivers only what is needed and the regulator stays as a safeguard. The pumps can run as main and spare or both together. On a failure the unit moves to the other pump, and if there is still no pressure it runs both at 100 %. If the pressure sensor fails, the pumps hold a current.

Setup

  1. Open the sectionActuators module, Pumps & relays section.
  2. Choose the schemeOn Pump scheme, set the delivery scheme and mode.
  3. Set the pressureOn Pump pressure: target, limit, emergency threshold and time.
  4. Fill in the curvesDuty by rpm for each pump.
  5. Set current limitsOn the Pump limits tab.
  6. VerifyOn the Test tab, run each pump for the set time with the engine stopped.
  7. SavePress Save to ECU.
