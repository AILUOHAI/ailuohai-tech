Electronic throttle

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The electronic throttle meters the air. This section sets up its sensors, motor and position controller.

How it works

A motor opens the throttle through an H-bridge and a spring closes it. Without current it rests in the limp position, about 7-8 %. Two position sensors move in opposite directions and the unit constantly compares them. Every millisecond the controller adds the spring holding term, a friction term and a PID on the position error, then scales the result to battery voltage. If the channels disagree for more than 150 ms, the throttle does not follow its target or the bridge fails, the bridge is switched off and the spring returns the throttle to the limp position.

Setup

  1. Open the sectionActuators module, Electronic throttle section.
  2. Check the sensorsOn the Throttle body tab, choose the inputs and sensor type.
  3. Choose the bridgeIn Motor bridge, select the bridge the motor is wired to.
  4. Learn the stopsEngine stopped, ignition on. Press the stop-learning button.
  5. Run auto-tuningFor about 20 s the unit measures the spring and friction and picks the PID. The throttle will move, so keep your hands clear.
  6. VerifyOn the Test tab, command 0, 25, 50, 75 and 100 %.
  7. SavePress Save to ECU.
