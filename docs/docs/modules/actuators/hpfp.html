HPFP

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The high-pressure fuel pump raises rail pressure for the GDI injectors. This section sets the valve, the cam and the pressure controller.

How it works

The pump plunger is driven by a camshaft lobe. A solenoid valve decides how much of the plunger stroke goes to the rail: the earlier it closes, the more fuel is delivered. The unit calculates the required delivery from the pressure target and fuel flow, converts it to a closing angle and sends a pulse for each lobe, allowing for the valve delay. The controller runs every 10 ms. If the rail sensor fails, the pump is switched off, injection is calculated at lift pressure and power is limited.

Setup

  1. Open the sectionActuators module, HPFP section.
  2. Set up the valveOn the Valve tab, enter the peak current, hold current and pulse length.
  3. Set the mechanicsOn Mechanics, set the lobes, plunger and cam position relative to the crank.
  4. Define the pumpsOn Pumps: how many there are and which rail they feed.
  5. Check the outputOn Test, send 1-3 pulses with the engine stopped.
  6. Tune the controllerWith the engine running, compare pressure with the target and adjust the gain if needed.
  7. SavePress Save to ECU.
