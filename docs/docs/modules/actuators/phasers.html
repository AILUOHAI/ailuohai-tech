Cam phasers

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

A cam phaser rotates the camshaft relative to the crankshaft. This section sets up the valves and the cam position controller.

How it works

The cam is turned by oil pressure directed by a PWM valve. The controller compares the target and current cam position and holds it with a PID around the holding duty. It works only when the engine is running, above 600 rpm, with oil warmer than 20 °C, 2 s after start and at least 100 kPa of oil pressure. Otherwise the valve has no current and the cam rests at its stop. Targets by engine state are not connected yet: in operation the cam holds its home stop, and the application can command a position for testing.

Setup

  1. Open the sectionActuators module, Cam phasers section.
  2. Choose the outputOnly LS1, LS2, LS7 and LS8 suit the valve: they have protection diodes.
  3. Check the valveOn a warm running engine, set the PWM by hand and see whether the cam moves.
  4. Run auto-tuningIt finds the stop, breakaway and holding duty and picks the PID. Previous values can be restored.
  5. Check the errorsOn the Errors tab there must be no active codes.
  6. SavePress Save to ECU.

Holding (intake)

PWM at which the cam stands still, by rpm × oil temperature: the start of the slow integrator (learned while running). The auto-tuning fills it.

Holding (exhaust)

PWM at which the cam stands still, by rpm × oil temperature: the start of the slow integrator (learned while running). The auto-tuning fills it.

PID (intake)

P, I, D by rpm × oil temperature; the auto-tuning fills them.

PID (exhaust)

P, I, D by rpm × oil temperature; the auto-tuning fills them.

Errors

Each valve: does not reach the target, no camshaft phase; reset.
