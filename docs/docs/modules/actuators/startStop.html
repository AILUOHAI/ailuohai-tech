Start-stop

“Actuators” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The section controls starting and stopping the engine with one Start-stop button and sets the outputs of the fuel pumps and the starter relay: which switch, which current is allowed, what counts as open load and short.

How it works

The button is the same in three places: at the top of the app window, on this tab and on the dash; the one pressed works. This is the real starter. Start is allowed only if the lever is at most 5 %, the starter is allowed and connected, and the shaft stands (above 300 rpm the starter is not switched on). Button modes (off by default): full auto - hold the button 1 s (against an accidental press), then the ECU cranks by itself until the engine runs and releases the starter at 600 rpm; the button can be released, pressing again cancels. Hold - the starter turns only while the button is pressed; once the engine runs the starter is released even if the button is still held. In both modes cranking is at most 10 s; if the engine did not start, the starter is released and a new try is possible only after a 5 s pause. Stop: on a running engine hold the button 2 s - injection and spark are switched off until the shaft stops; a short press does nothing. If the link with the button is lost, it counts as released. Outputs: pump 1 and pump 2 go to switch U35 (J4.30), U36 (J4.31) or not connected (the output is never switched on, its errors are off); one switch - one pump; change only with the engine stopped. The starter relay is always on U37 (J1.9), there is no choice. The ECU measures the switch current every 10 ms. Below the lowest current with the output on - open load (with the output off an open load is not seen). Above the highest - the output is switched off, retried and then latched until Clear fault. Above the hard limit - switched off at once. The switch cuts a short to ground and overheating itself; +12 V on an output that is off is a short to battery. Inrush current right after switching on is not judged. All settings here are protections; only a human changes them. Flashed, but not yet checked on the bench with a real starter and pumps.

Setup

  1. Connect the outputsPump 1 and pump 2: choose the switch as wired in your harness; an unused pump - not connected.
  2. Set the current limitsHighest current about twice the working one, lowest - to see a broken wire.
  3. Allow the starterTurn on Starter allowed and choose the button mode.
  4. Set the cranking timeFor example 5 or 10 s.
  5. CheckPlugs out, fuel off: press the button and make sure the starter cranks and is released.
  6. SavePress Save to ECU.
