Faults

“Idle” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The boat must get home. This section sets how idle behaves on faults.

How it works

If the coolant sensor fails, the target becomes one set number and there is no after-start raise. When running by camshaft, the target and torque reserve are higher, and the fast regulator ignores the speed rate because that signal is noisy. If the lever sensors fail, the target stays at or above the hold speed. At low voltage the target rises for charging. If the throttle is in the fail-safe position, ignition holds the speed even with stage 3 off, and speed may be above the target. Cylinders are not shut off. Limiters and protections do not cut torque below what idle needs, but the rev limiter works as usual.

Setup

  1. Open the sectionIdle module, Faults section.
  2. Set the coolant fault target1000 rpm by default: speed must be stable even on a cold engine.
  3. Set camshaft runningTarget 150 rpm higher, reserve 10 Nm larger.
  4. SavePress Save to ECU.
  5. Verify at the mooringWith the engine off, unplug the coolant sensor, start the engine and confirm the speed moves to the set target. Stop the engine and reconnect the sensor.
