Adaptation

“Idle” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Adaptation stores a constant torque correction so the regulator does not have to hold it every time.

How it works

A loss model is never exact, so at steady idle the regulator constantly holds some torque. Adaptation slowly moves it into a learned correction, separately for a cold and a warm engine, and blends both between the limits. The unit learns only when speed has been near the target for the set time, there is no catch, loads have not switched, there are no faults or limits, and the coolant and intake pressure sensors are healthy. The correction is stored in the unit and erased with a button.

Setup

  1. Tune stages 1-5 firstAdaptation is turned on last.
  2. Open the sectionIdle module, Adaptation section.
  3. Check the conditionsBy default 20 and 70 °C, ±40 rpm, 5 s, rate 0.1, limit ±20 Nm.
  4. Turn on stage 6On Idle now.
  5. Watch the correctionThe regulator part at steady idle should go to zero, and the correction must not hit the limit.
  6. After major retuningErase the correction with the Clear button.
  7. SavePress Save to ECU.
