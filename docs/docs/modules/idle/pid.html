Regulator

“Idle” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Two regulators hold the speed. The main one works through air, the fast one through ignition.

How it works

The main PID compares speed with the target and changes the torque request, and the throttle carries it out. Air reaches the cylinder with a delay, so fast dips have a second path. The unit holds slightly more air than needed by the torque reserve and sets ignition a little later than the best angle. When speed falls, ignition moves earlier at once and releases the reserve. The main regulator then corrects the air and ignition returns to the middle of the reserve. The reserve never exceeds 60 % of the idle torque. While stage 3 is off, ignition follows the map and only air works.

Setup

  1. Open the sectionIdle module, Regulator section.
  2. Tune the PIDOn the PID tab the numbers go in order: kp, ki, kd, D filter, output min and max, integral min and max, deadband. Factory values: kp 0.15, ki 0.6, kd 0.002.
  3. Change one at a timeFirst kp, then ki. Raise kd only if needed.
  4. Turn on stage 3On Idle now, once stage 2 holds the speed steadily.
  5. Set the reserveA curve by coolant, 25 to 12 Nm by default.
  6. Tune the fast regulatorBy error 0.5 Nm per rpm, by fall rate 0.02.
  7. SavePress Save to ECU.
