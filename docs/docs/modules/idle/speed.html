Idle speed

“Idle” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets which speed to hold and how smoothly to enter and leave idle.

How it works

The base target is a curve by coolant temperature, 1100 to 750 rpm by default. Added to it are the after-start raise, the low-voltage raise for charging the battery, and the raise when running by camshaft. The target rises at once and falls no faster than the set rate. Idle engages when the lever is below the threshold and speed has entered the window above the target. The lever gap stops the mode from toggling at the boundary. From above, speed approaches the target smoothly, and when the lever is pressed the larger of the two requests is used, so there is no jerk.

Setup

  1. Open the sectionIdle module, Idle speed section.
  2. Set the curveOn the Idle speed by coolant tab, set the target for a cold and a hot engine.
  3. Set the after-start raiseBy default +400 rpm at −20 °C to +100 at 60 °C, held for 5 s and removed over 30 s.
  4. Check the lever threshold1 % with a 1 % gap by default.
  5. Set the window and approachWindow 400 rpm, approach from above 300 rpm per second.
  6. SavePress Save to ECU.
