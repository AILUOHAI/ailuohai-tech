Now and stages

“Idle” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This screen shows what idle control is doing now and what its torque is made of, and holds the tuning stage switches.

How it works

On a boat the propeller is always connected to the engine, so at idle the engine turns the propeller. The unit requests torque rather than a throttle percentage. Two paths deliver it: air through the throttle, slowly, and ignition, quickly, within the reserve. Fuel and spark are never cut at idle. There are four states: lever pressed, lever released with speed still high, holding speed, and catch on a speed drop. Tuning goes in stages, each with its own switch at the bottom of the tab. By default only the speed regulator is on.

Setup

  1. Prepare the throttleRun the auto-calibration: the throttle must sit steadily at 1-5 %.
  2. Stage 1: manual torqueTurn all stages off and set the manual torque so the warm engine stands near the target. A large value points to an error in the model.
  3. Stage 2: speed regulatorTurn it on and tune the PID: target ±30 rpm, lever release without a dip or hunting.
  4. Stage 3: reserve and ignitionIdle should become smoother than at stage 2.
  5. Stage 4: loadsThe regulator part must not jump when a pump switches on.
  6. Stage 5: catchA sharp lever release from high speed without a deep dip or false catches.
  7. Stage 6: adaptationTurn it on last, otherwise it learns the tuning mistakes.
  8. SavePress Save to ECU. If things get worse, turn off the last stage.
