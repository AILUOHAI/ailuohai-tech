Knock: detection

“Ignition” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingSpark and knockWhat is in the application

Purpose

The unit listens to the knock sensors in a window after each cylinder's TDC and decides whether knock occurred. Each cylinder keeps its own background level, so a noisy cylinder does not trigger false detections.

How it works

The signal passes through one or two bands at the combustion chamber resonances. The knock feature is compared with the cylinder background: if the window is louder than the background by more than the set ratio, it is knock. The factory threshold is 2.5. There are two sensors, each with its own cylinders. A cylinder whose sensor is not in use has no knock control. The background learns by itself, and if the noise curve is enabled, it starts from that curve and stays in a corridor around it. When filling rises faster than 60 % per second, the threshold is multiplied by 1.3 and the background follows the signal faster. Long knock cannot raise the background to its own level, because background growth per window is limited.

Firmware defaults: threshold 2.5, step 1.5°, gain 0.5.

Setup

  1. Open the spectrographThe “Knock” button on the left bar of the application.
  2. Capture noise without knockAt different speeds, store the points in the noise map.
  3. Place the bandsOn the chamber resonance, away from gearbox noise. Press “Apply to ECU”.
  4. Place the windowUsing the level-by-angle chart after TDC.
  5. Set the thresholdSlightly above the quiet background. Too low a threshold causes false retard.
  6. Check transientsDuring sharp load increases the threshold rises by a separate factor.
