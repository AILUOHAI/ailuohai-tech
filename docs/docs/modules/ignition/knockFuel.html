Knock: fuel and fault

“Ignition” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The unit estimates fuel quality and picks a point between the 92 and 100 maps. If the knock sensor fails, it moves to the safe map and limits the engine.

How it works

Factor k falls quickly when the average retard is high and rises slowly only after long quiet running under load. A knock event at that load resets the quiet-running count. After refuelling k returns to the start value, because the new fuel is unknown. The unit notices refuelling both while running and between power-ups. A sensor fault means an open or short on a sensor in use, with the engine running and the supply normal. While the fault is active, the 92 map runs with the safety retard, and the learned k is kept.

Setup

  1. Set the start valueThe engine begins from it after refuelling.
  2. Check the level sensorRefuelling is detected by a level rise of more than 10%. Without the sensor there is no refuel reset.
  3. Set the rise rateRising must be much slower than falling.
  4. Set the fault reactionSafety retard and the torque and filling shares with a failed sensor.
  5. If you know the fuelSet the value manually: 0 for 92, 1 for 100.
