Voltages

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section shows the on-board voltage and the 5 V sensor reference. Measurements, coils and injectors all depend on them.

How it works

Starter sag is not an error: low-voltage checks begin 5 s after start and require a 1 s hold. Below 9 V the unit does not test sensors and outputs, to avoid false codes. If voltage stays below 12.6 V for more than 10 s while running, idle rises by 200 rpm for charging and returns once voltage is 0.3 V above the threshold.

Setup

  1. Open the sectionSensors module, Voltages section.
  2. Check the batteryCompare with a multimeter at the ECU terminals.
  3. Check the referenceReference 5 V must be in the normal range.
  4. Check chargingWith the engine running, voltage must rise above the resting voltage.
  5. Review the limitsOn Errors & limits, check the values for your system.
  6. SavePress Save to ECU if you changed the limits.
