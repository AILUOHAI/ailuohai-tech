Fuel level

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The sensor shows how much fuel is in the tank, in percent.

How it works

The level sensor is a variable resistor in the tank. The unit measures its resistance through a 200 Ω reference resistor and converts the result to percent with a curve. Each tank has its own curve, so it is captured while filling.

Setup

  1. Open the sectionSensors module, Fuel level section.
  2. Choose the inputNo input is assigned by default; select it in the Pin field.
  3. Record an empty tankNote the reading with the tank nearly empty.
  4. Fill in portionsAfter each portion note the reading and percent.
  5. Enter the curvePut the points into the table.
  6. SavePress Save to ECU.
