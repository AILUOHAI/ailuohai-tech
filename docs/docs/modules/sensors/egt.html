Exhaust temperature (EGT)

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The sensor shows the exhaust gas temperature of each head and feeds the exhaust overheat protection.

How it works

The thermocouple is read by the wideband + EGT module, which sends the result to the unit over CAN. The module compensates for the cold junction itself. The thermocouple type and correction are set in the module. With no sensors, the protection runs on the exhaust temperature model.

Setup

  1. Open the sectionSensors module, Exhaust temperature (EGT) section.
  2. Enable the sourceIn Lambda, Sensors & heating tab, tick take EGT from the module.
  3. Check the moduleModule CAN tab: press Read.
  4. Choose the thermocoupleSet the type and a correction if needed.
  5. WritePress Save to module.
  6. Check the readingsOn a cold engine EGT is close to air temperature and the thermocouple is OK.
