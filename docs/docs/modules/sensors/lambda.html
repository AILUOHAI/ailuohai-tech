Lambda

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The oxygen sensor shows the mixture in the exhaust, and the unit uses it to correct fuel.

How it works

Each head can have a narrowband sensor on an ECU input or a wideband through a CAN module. A narrowband only shows rich or lean: by default above 0.6 V is rich and below 0.3 V is lean. For a wideband, the module does the heating and calculation and the unit receives a ready λ. Heating starts gently and full power comes after the dew point, so condensate does not crack the ceramic.

Setup

  1. Open the settingsLambda section, Sensors & heating tab.
  2. Choose the typeFor each head: narrowband, wideband or none.
  3. Set the connectionInput and heater output for narrowband, module number for wideband.
  4. Check the moduleModule CAN tab: press Read and confirm the sensor type.
  5. Free-air calibrationFor a wideband: sensor removed and in clean air, then press Free-air calibration.
  6. WriteSave to module for the module and Save to ECU for the unit.
  7. Check on the engineOn Readings the sensor must reach the ready state.
