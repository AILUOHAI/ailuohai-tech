Fuel pressure, low

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The sensor shows the pressure in the low-pressure line ahead of the high-pressure pump.

How it works

The sensor outputs a voltage proportional to pressure. The unit converts it along a straight line through two datasheet points. A voltage below 0.2 V or above 4.8 V means an open or short circuit. By default the sensor is on the fast input AV1.

Setup

  1. Open the sectionSensors module, Fuel pressure, low section.
  2. Choose the inputSelect the board input in the Pin field.
  3. Enter two pointsVoltage and pressure from the sensor datasheet.
  4. Check with no pressureWith the engine stopped, the reading must match what you expect.
  5. Compare with a gaugeWith the engine running, compare against a mechanical gauge.
  6. Set up errorsOn the errors tab, check the bounds and the substitute value.
  7. SavePress Save to ECU.
