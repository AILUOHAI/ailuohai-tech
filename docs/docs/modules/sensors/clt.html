Coolant temperature

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksWiringWhere it is in the applicationSetupWhat uses this temperatureTroubleshootingWhat is in the application

Purpose

The coolant temperature sensor (CLT) reports the thermal state of the engine. It is installed in the cooling jacket, usually near the thermostat.

The unit uses this temperature to choose the start dose, warm-up enrichment and idle speed, and limits torque in steps when the engine overheats.

Important: the sensor is passive. The unit calculates temperature from its resistance, so the calibration must match the specific sensor.

How it works

The sensing element is an NTC thermistor: resistance falls as temperature rises. The sensor is connected to ground and forms a voltage divider with a 10 kΩ reference resistor from 5 V.

What R25 and β mean

A thermistor curve is described by two numbers. R25 is the resistance at 25 °C, where the curve is anchored. β shows how quickly resistance falls as the sensor heats up: the larger β, the steeper the curve. It is measured in kelvin, typically 3000…4500 K for automotive sensors.

R(T) = R25 · eβ · (1/T − 1/298.15), with T in kelvin: T = °C + 273.15

Example: three sensors with the same 2500 Ω at 25 °C but different β. At 25 °C they are identical; at operating temperature they diverge. The last column shows the error if the sensor's β is 3500 but the unit is set to another value.

βResistance at 90 °CUnit reads at a true 90 °C
3000 K413 Ω104 °C
3500 K306 Ω90 °C
4000 K226 Ω80 °C

If β is unknown, measure the sensor resistance with a multimeter at two temperatures, for example 25 °C and 90 °C, and calculate:

β = ln(R1 / R2) / (1/T1 − 1/T2) = ln(2500 / 306) / (1/298.15 − 1/363.15) ≈ 3500 K

β is an approximation, most accurate between the two measured points. If the datasheet has a temperature-resistance table, enter that instead: the application stores the sensor calibration as a 16-point table.

Wiring

  1. The sensor has two wires with no polarity.
  2. One wire goes to the ECU input. By default this is IO-5, pin J1.26.
  3. The other goes to the ECU sensor ground, not to the chassis or engine block.
  4. Check the pins against the pinout.

Setup

  1. Connect the sensorTwo wires, as described above.
  2. Open the tabSensors → Coolant temperature → Calibration & raw.
  3. Check the readingOn a cold engine the temperature should be close to the ambient air.
  4. Verify the calibrationIf the reading is off, enter the values from the sensor datasheet.
  5. Check heatingWarm the engine or the sensor: the temperature should rise smoothly, without jumps.
  6. Save to ECUOtherwise the setting is lost when the power is switched off.
