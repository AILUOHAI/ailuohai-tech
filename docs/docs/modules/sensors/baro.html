Barometer

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The barometer measures atmospheric pressure, which is needed for the air calculation and for operation at different altitudes.

How it works

The sensor is on the ECU board. The unit checks it three ways: against an allowed range, by rate of change, and against MAP on a stopped engine. Real weather does not change pressure faster than 2 kPa in 10 s. If the barometer is faulty, the unit uses MAP on a stopped engine, then the last good value, then 101.3 kPa.

Setup

  1. Open the sectionSensors module, Barometer section.
  2. Check the readingWith the engine stopped it must match MAP and the weather report for your altitude.
  3. Check the stateThe For the engine field must show sensor OK.
  4. Look at the errorsOn Errors & limits there must be no active P2226…P2229 codes.
