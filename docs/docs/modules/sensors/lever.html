Lever / pedal

“Sensors” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The lever sensor passes the operator's request to the unit. It is one of the most important signals, so two independent channels are normally used.

How it works

By default the channels are on inputs AV3 and AV4 and work as mirrors: one rises while the other falls. If they differ by more than the tolerance, code P2138 is set and the lower value is used. If one channel fails, the lever is limited to 50% and rises no faster than 50%/s. If both fail, the lever is 0 and the engine holds 1500 rpm so the boat can reach shore.

Setup

  1. Open the sectionSensors module, Lever / pedal section.
  2. Check the inputsBy default sensor A is on AV3 and sensor B on AV4.
  3. Release the leverPress the Released button.
  4. Push to the stopPress the Pressed button.
  5. Check the travelMove the lever slowly: both channels and the result change without jumps.
  6. Test a failureWith the engine stopped, unplug one channel and confirm a code appears.
  7. SavePress Save to ECU.
