Adaptation

“Start” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Adaptation gradually adjusts the start dose to the real fuel and engine. It is off by default.

How it works

The unit looks at how many injections per cylinder were needed before catching. A slow start raises the factor by one step. A fast start lowers it by a quarter step. A failed start with fuel delivered for a long time raises it by one step. It learns only from clean starts: no flood clear, not a repeat start, and no continued injection count. There is one factor for all temperatures, stored in the unit. This is a basic version: it does not yet check lambda after the start or exclude starts with a weak battery or low pressure, so turn it on after the dose is set up.

Setup

  1. Set the dose firstAdaptation corrects a tuned dose and does not replace tuning.
  2. Open the sectionStart module, Adaptation section.
  3. Check the limitsBy default the factor is 0.8 to 1.5, step 0.04.
  4. Check the thresholdsA slow start is more than 6 injections, a fast one no more than 2.
  5. Turn it onSet Start dose adaptation to 1.
  6. Watch the factorIf it hits a limit, look for the cause in the fuel, injectors or dose.
  7. SavePress Save to ECU.
