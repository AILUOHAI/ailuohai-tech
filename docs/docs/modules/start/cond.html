Conditions

“Start” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Conditions decide when the start is over, when to protect the starter, and what kind of start this is: normal, repeat, hot or flood clear.

How it works

The start ends when speed stays above the End of start curve for 200 ms. If cranking lasts longer than the starter protection time, injection stops until the shaft has fully stopped. Repeat start: the engine ran for more than 2 s and has been stopped for less than the set time, so the dose is multiplied by its own factor. After a failed attempt within the same time, the injection count continues so that the large first doses do not flood the plugs. Hot start: coolant and air are both at or above their thresholds. Flood clear: the lever is at or above the threshold while cranking, so there is no fuel, spark stays on and the throttle opens fully. The unit knows the stopped time only while it stays powered.

Setup

  1. Open the sectionStart module, Conditions section.
  2. Check starter protectionThe default is 15 s. Compare it with the starter datasheet.
  3. Check flood clearThe lever threshold is 90 %. A value of 101 turns flood clear off.
  4. Set repeat and hot startBegin with the factory values and adjust from real starts.
  5. Check the end of startOn the End of start tab, the threshold must be above cranking speed but below idle.
  6. SavePress Save to ECU.
