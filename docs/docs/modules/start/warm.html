Warm-up

“Start” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Until the engine is warm, the mixture is kept richer. This curve sets how much richer by the current coolant temperature.

How it works

The lambda target from the main map is multiplied by this curve. A value below 1 means richer. In the factory setting the factor rises smoothly from 0.82 at −30 °C to 0.995 at 75 °C, so the enrichment almost disappears by operating temperature. Unlike the start tables, this one uses the current coolant temperature rather than the one stored at the start. The numbers in the screenshot are an example.

Setup

  1. Open the sectionStart module, Warm-up section.
  2. Find the operating pointThe green point on the chart shows the current coolant temperature.
  3. Set the cold partIf the cold engine runs rough, reduce the factor at that point.
  4. Check when warmAbove operating temperature the factor should be near 1.
  5. SavePress Save to ECU.
