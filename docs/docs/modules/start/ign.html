Start ignition

“Start” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

The map sets the spark angle while cranking by speed and start temperature.

How it works

At low speed the spark is placed closer to TDC: an early spark on a slow shaft kicks back against the starter. As speed rises the angle grows so the engine catches more firmly. By default the angle runs from 5° at 150 rpm to 12° at 1200 rpm, with another 2° below 0 °C. The spark stays on during flood clear. This map works only while cranking, after that the normal model calculates ignition.

Setup

  1. Open the sectionStart module, Start ignition section.
  2. Find the operating pointWhile cranking, the point on the map shows the current speed and temperature.
  3. Change in small steps1-2° at a time, only in the area the start really uses.
  4. Smooth itNo sharp steps between neighbouring cells.
  5. SavePress Save to ECU.
