After start

“Start” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Right after catching, the engine needs extra fuel. This section sets that enrichment and how quickly it fades.

How it works

The chamber and intake walls are still cold, and part of the fuel settles on them as a film. So a percentage based on start temperature is added to the normal dose: by default from +60 % in deep cold to +8 % when hot. The enrichment fades by engine cycles rather than seconds, so it behaves the same at any speed. By default it is gone after 600 cycles when cold and 160 when hot. When less than 0.5 % remains or the time limit passes, the mode ends. On a repeat start, the enrichment is multiplied by its factor.

Setup

  1. Open the sectionStart module, After start section.
  2. Set the enrichmentOn the Enrichment tab, set the percentage by temperature: 0.5 means +50 %.
  3. Set the decayOn Decay by cycles, set what share of the enrichment remains.
  4. Check the limitBy default the mode lasts no more than 60 s.
  5. Check with lambdaThe mixture must not go lean in the first seconds.
  6. SavePress Save to ECU.
