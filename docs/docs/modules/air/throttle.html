Throttle model

“Air (filling)” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets the flow area the throttle opens at each position. The unit uses it to find the throttle angle for the air it needs.

How it works

The torque asked by the lever and the idle controller becomes filling, filling becomes air mass, and air mass becomes the required intake pressure through the Cylinder filling model. Air flow equals the mass per cycle times the number of cylinders and the speed. The orifice flow equation gives the area needed for that flow with atmospheric pressure before the throttle and the required pressure after it. The area-by-position curve turns the area into an angle. If the required pressure is at least 97 % of atmospheric, the throttle opens fully. The angle comes only from the model; there is no angle trim from the intake pressure sensor yet. So an inaccurate curve changes intake pressure and torque, but not the mixture: fuel is calculated from the measured pressure. At idle the speed controller removes the error. The model has a second job: if the intake pressure sensor fails, the unit calculates the pressure from throttle, speed and barometer. While the sensor is healthy and running is steady, the unit learns an area correction from 0.6 to 1.6 so that this substitute is more accurate. The factory curve is for a 90 mm throttle: 15 mm² closed and about 5200 mm² fully open.

Setup

  1. Check the throttleIn the Actuators module, Electronic throttle section, learn the stops: 0 and 100 % must match the stops.
  2. Filling firstThe area curve is accurate only when the filling model is already set up.
  3. Calculate the pointsIn steady running the flow is air per cycle times cylinders times speed divided by 120. The area for that flow at the known barometer and intake pressure goes into the point of the current angle.
  4. Check transientsSharp lever moves must pass without lambda dips or spikes.
  5. SavePress Save to ECU.
