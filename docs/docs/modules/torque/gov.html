Speed governor

“Torque & limits” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

Experimental mode, off in the factory setup. This section turns on a mode in which the lever sets speed rather than torque. The unit picks the torque itself, so the same lever gives the same propeller thrust in any wind and at any boat speed.

How it works

A four-point curve turns the lever into a speed target. Factory points: 2 % - 1200, 30 % - 2500, 70 % - 4000, 100 % - 5500 rpm. The target changes no faster than 1500 rpm per second and is never below the idle target. Torque is the sum of a propeller-law feed-forward and a PI on the speed error. The feed-forward equals the learned propeller coefficient times the square of the target. Until the coefficient is learned, only the PI works. Factory gains: P 0.15 Nm per rpm, I 0.25 Nm per rpm per second. The request stays between −30 and 600 Nm. The mode switches on and off while running without a torque jump. Lever released: normal idle control works. All limiters and the smooth torque rise act as usual.

Setup

  1. Normal mode firstThe mode makes sense after the torque model and idle are set up.
  2. Learn the propellerThe propeller coefficient is learned while running in normal mode: run at different speeds.
  3. Set the curveLever points rise, and so do the speeds at the points.
  4. Turn on on the waterTurn it on at low speed and check that the speed holds under different loads.
  5. SavePress Save to ECU.
