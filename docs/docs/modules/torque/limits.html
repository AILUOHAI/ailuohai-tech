Limits

“Torque & limits” module: what it is, how it works, how to set it up.

Ctrl K
PurposeHow it worksSetupTroubleshootingWhat is in the application

Purpose

This section sets the speed limit and what to do on an overspeed above it.

How it works

The limiter looks not at the current speed but at a forecast: speed plus its rate of rise times a lead of 0.25 s. This gives the throttle and the manifold time during fast acceleration. In a 500 rpm band below the limit the shaft torque smoothly goes to zero; at the limit the engine only covers its own losses. Torque is taken first by spark, then by air; fuel and spark are not switched off. The factory limit is 6500 rpm. The lowest of the limits acts: this one, go-home mode on a level R2 fault, and the cam-run limit. The emergency cut is off in the factory setup. If enabled, all cylinders are cut on an overspeed of 800 rpm above the limit until the speed drops below the limit. This is for the case when the propeller comes off the shaft.

Setup

  1. Set the limitFrom the engine and propeller data. The unit works up to 15000 rpm.
  2. Set the bandA wide band is softer but takes torque earlier.
  3. Set the leadIf the speed overshoots the limit on sharp acceleration, increase the lead.
  4. Decide on the cutEnable it only if overspeed is dangerous for the engine, for example when the propeller comes off.
  5. SavePress Save to ECU.
